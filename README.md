## Instrucciones:

**📦️ Para instalar el port:**

Debes instalar la última versión [PortMaster](https://portmaster.games/) 


1. Descarga el repositorio
2. Carga "Pancito Merge.sh" en tu carpeta de Ports.
En ArkOS / dArkOS es: 
```
/roms/ports/
```
3. Carga la carpeta "pancitomerge" en tu carpeta de ports


**🕹️ Para instalar el juego**
1. Compra **PancitoMerge** en Steam o Itchio
2. Ve al directorio de descarga, normalmente se encuentra en:
  
**Linux:**
 ```bash
home/TuUsuario/.local/share/Steam/steamapps/common/PancitoMerge/PancitoMerge.pck
 ```
 **Windows:**
 ```cmd
 C:\Program Files (x86)\SteamLibrary\steamapps\common\PancitoMerge\PancitoMerge.pck
```

4. Busca el achivo .pck
5. Transfiere este archivo a tu consola en la carpeta:

```
/roms/ports/PancitoMerge/PancitoMerge/PancitoMerge.pck
```

6. Ejecuta el juego
7. ¡Disfruta!

## 🧪️  Para colaborar 

Prueba el port en tu consoloa y reporta cualquier bug Usando la plantilla de bugs en el menú de [Issues](https://github.com/blueIronThiever/PancitoMerge-Port/issues) dentro de este repositorio.
También, si no hay errores puedes reportar que todo está bien usando la pantilla report en el menú de issues [Issues](https://github.com/blueIronThiever/PancitoMerge-Port/issues)

Agregué la capacidad de tomar capturas dentro del juego las cuales te pueden servir para reportar errores

Para tomar capturas usa:

| Botón | Acción |
|--|--|
| SELECT | Capturar pantalla |

Las capturas las puedes encontrar en tu consola, dentro de la carpeta:

```
.../ports/pancitomerge/conf/godot/app_userdata/PancitoMerge/
```
